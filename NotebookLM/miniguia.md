# Miniguia NotebookLM

## Como utilizar o projeto

1. Acesse o NotebookLM.
2. Adicione fontes confiáveis sobre o tema estudado.
3. Faça perguntas utilizando prompts estruturados.
4. Analise as respostas geradas.
5. Organize os principais aprendizados em uma base de conhecimento.

## Exemplos de perguntas

- Quais são os principais ensinamentos de Warren Buffett?
- Quais critérios ele utiliza para avaliar empresas?
- Como aplicar Value Investing na análise de investimentos?
